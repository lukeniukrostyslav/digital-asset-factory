# BUILD-12E8 — Cross-language acceptance

Status: 100% of BUILD-12E.

Accepted scope:
- Five physical editions exist: EN, IT, FR, DE, RU.
- Each edition contains the eight core concepts: Life Areas, Goals, Projects, Tasks, Habits, Reviews, Captures, Notes.
- Core hierarchy is preserved across editions: Life Area → Goal → Project → Task.
- Habits link to Life Areas; Reviews link to Goals/Projects/Tasks/Habits; Notes link to Life Areas/Projects/Goals; Captures link to Life Areas.
- Primary localized table views were created for Goals, Projects and Tasks in all five editions.
- Visible English leftovers identified during acceptance were normalized where safe (notably IT/FR/DE/RU status/notes and task relation labels). Formula-sensitive core names in the original specification remain subject to later live-formula validation.

Release limitation carried forward:
This closes the five-language physical build block, not the product release. Advanced view filter/sort behavior still needs live acceptance, and Android/mobile visual QA, desktop QA, Sample→Blank duplication/import, packaging, store and checkout remain open in BUILD-12F onward.
