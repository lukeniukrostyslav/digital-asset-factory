# PRODUCT-BUILD-05 — ONBOARDING / QUICK START

Дата: 24.09.2026

## Status

PRODUCT-BUILD-05: 100%

## 1. Цель

Сделать первый опыт настолько простым, чтобы пользователь мог перейти от пустого workspace к реальному выполненному действию без изучения всей системы.

Главный принцип:

SHOW → DO → SEE RESULT → EXPAND.

## 2. FIRST-RUN FLOW

Шаг 0 — Language
→ выбрать EN / IT / FR / DE / RU.

Шаг 1 — Start Here
→ понять систему за 60–90 секунд.

Шаг 2 — Life Areas
→ выбрать/создать 3–5 сфер жизни.

Шаг 3 — ONE Goal
→ создать только одну текущую цель.

Шаг 4 — ONE Project
→ превратить цель в один конкретный проект.

Шаг 5 — ONE Task
→ создать ближайшее действие.

Шаг 6 — TODAY
→ открыть Today.

Шаг 7 — COMPLETE
→ выполнить/закрыть первую задачу.

Шаг 8 — REVIEW
→ показать, зачем существует Review.

Шаг 9 — EXPAND
→ только теперь показать остальные возможности.

## 3. START HERE PAGE

Start Here не является database.

Структура:

### Welcome

"Your life system starts here."

### What this system does

Capture → Clarify → Plan → Execute → Review → Adjust.

### The rule

Do not build everything on day one.

### First result

"Create one goal, one project and one task."

### Navigation

1. Start Here
2. Life Areas
3. Goals
4. Projects
5. Tasks
6. Today
7. Reviews

### Optional

AI Assistant
Advanced Guide
Help

## 6. FIRST GOAL

Prompt:

"What matters most right now?"

Fields:
Goal
Life Area
Status
Target Date
Progress

Status = Active

## 7. FIRST PROJECT

Prompt:

"What project would move this goal forward?"

Fields:
Project
Goal
Life Area
Status
Target Date
Next Action

Default:
Status = Planning.

After creation:
move to Active once work begins.

## 8. FIRST TASK

Prompt:

"What is the next physical/digital action?"

Examples:
- Send the email.
- Book the appointment.
- Open the document.
- Make the call.
- Write the first paragraph.

Avoid vague tasks such as:
"Work on project."

Fields:
Task
Status
Due
Priority
Project.

Default:
Status = To Do.

## 9. TODAY

After task creation, onboarding points directly to Today.

Today shows:
- current open tasks;
- overdue tasks when applicable.

No dashboard tour before the user sees the result.

## 10. FIRST SUCCESS

Success state:

"You created your first connected action."

Show relationship:

Life Area
↓
Goal
↓
Project
↓
Task
↓
Today

This teaches the architecture through use rather than explanation.

## 11. REVIEW INTRODUCTION

After first task completion:

"Now you know how to execute.
Reviews help you decide what comes next."

Open Weekly Review template.

Prompts:
- What moved forward?
- What is still important?
- What should I do next?
- What can I remove?

Do not force the user to fill a long review during onboarding.

## 18. HELP SYSTEM

Three levels:

### Inline Help
One sentence near the action.

### Quick Start
Complete first setup.

### Advanced Guide
Explain relations, views, formulas, AI and customization.

No mandatory video course.

## 19. EMPTY STATES

Every important view gets a useful empty state.

Today:
"No tasks due today. Add your next action."

Goals:
"Create one goal to give your system direction."

Projects:
"Turn a goal into a project."

Capture:
"Drop anything here. Process it later."

Reviews:
"Your next review will appear here."

## 20. ANTI-OVERWHELM RULES

Do not require:
- 20 goals;
- 50 tasks;
- complete habit setup;
- widgets;
- external integrations;
- AI;
- formulas knowledge;
- custom dashboards.

The system must work with:
1 Goal
1 Project
1 Task.
