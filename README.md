# DIGITAL ASSET FACTORY

Проект по созданию и продаже цифровых продуктов с минимальными первоначальными затратами.

## Цель

Создавать полезные цифровые продукты один раз, размещать их на внешних маркетплейсах/платформах и получать продажи без собственного VPS, постоянного сервера или обязательного собственного сайта.

## Первый продукт

**AI MONEY ORGANIZER** — набор для личного финансового планирования:
- Excel/Sheets dashboard;
- бюджет;
- учёт расходов;
- трекер долгов;
- цели накоплений;
- годовой обзор;
- printable PDF;
- AI prompts.

## Принцип проекта

Сначала создаём один качественный MVP → проверяем спрос → улучшаем → создаём следующие продукты на основе той же производственной системы.

Не считать доход гарантированным или полностью пассивным: продажи требуют первоначальной работы, качественных листингов и периодического контроля.

Приоритет:
1. **Payhip Free** — стартовый вариант без ежемесячной платы; 5% transaction fee плюс комиссии платёжных провайдеров. citeturn0search1turn0search14
2. **Gumroad** — без ежемесячной платы; для прямых продаж сейчас 10% + $0.50 за транзакцию, а продажи через Discover имеют отдельную комиссию. citeturn0search4turn0search5
3. **Etsy** — тестировать после подготовки продукта; здесь есть платные listings и комиссии, поэтому Etsy НЕ считается каналом с нулевыми расходами. citeturn0search2turn0search7

Правило: **до первых продаж не покупать VPS, домен, хостинг, рекламу или платные SaaS-инструменты без отдельного решения владельца проекта.**
