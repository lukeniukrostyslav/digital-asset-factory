## Product gap requirements

Our product should retain its differentiator of a broader personal-finance command center while closing the following presentation gaps:

1. Dashboard should communicate:
   - Income
   - Expenses
   - Net Cash Flow
   - Debt
   - Savings
   - Net Worth
   - Budget Remaining
   - Savings Rate
   - Top Spending Category
   - account balance context

2. Add a clear visual hierarchy:
   - page title
   - period/language controls
   - primary KPIs
   - secondary insights
   - action/review sections
   - supporting detail

3. Working sheets should share:
   - consistent header treatment
   - consistent input-cell treatment
   - consistent calculated-cell treatment
   - consistent spacing
   - predictable column widths
   - readable mobile labels

4. Keep the four-language system coherent.

5. Avoid copying competitor wording, layout or visual assets.

6. Do not add features merely for feature count. Every addition must improve the review workflow and survive the compatibility QA gate.

## Premium UX target

The product should feel like a single operating system for personal finance:
Start Here -> Setup -> Transactions -> Budget -> Bills -> Debt -> Savings -> Accounts -> Net Worth -> Insights -> Cash Flow -> Annual Review -> Dashboard.

The Dashboard is the review destination; the other sheets are structured workspaces.

## Release constraint

Android compatibility remains a hard gate. Visual features must be reintroduced in controlled layers only after the conservative compatibility core is accepted.
