# WORK RULES

1. Все основные решения проекта сохраняются в GitHub.
2. Каждый завершённый блок получает checkpoint.
3. Проценты должны быть честными.
4. Не считать идею выполненной только потому, что написан документ.
5. Не создавать новые продукты до проверки текущего продукта, если это приводит к распылению.
6. Сначала English MVP.
7. Сначала бесплатные/без ежемесячной платы каналы.
8. Не покупать VPS/домен/сайт/рекламу на старте.
9. Не обещать пассивный доход или гарантированные продажи.
10. Любые финансовые/налоговые утверждения проверять по актуальным официальным источникам.
11. Не копировать чужие продукты, бренды, тексты или защищённый дизайн.
12. Перед публикацией каждый файл проходит QA.
13. После публикации сохранять URL, дату, цену и версию.
14. Изменение продукта после публикации фиксировать как новую версию.
15. GitHub — источник истины по архитектуре и состоянию проекта.
