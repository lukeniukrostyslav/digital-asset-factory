# SELLING CHANNELS

## 1. Payhip — PRIMARY ZERO-FIXED-COST TEST

Free Forever:
- $0/month;
- 5% transaction fee;
- unlimited products/revenue;
- PayPal/Stripe fees still apply.

Источник: официальная страница Payhip. citeturn0search1turn0search14

Почему первым: можно тестировать цифровой продукт без ежемесячной подписки.

## 2. Gumroad — SECOND TEST

Нет ежемесячной платы.
Прямые продажи: 10% + $0.50 за транзакцию; Discover sales: 30%. citeturn0search4turn0search5

## 3. Etsy — LATER

Etsy имеет $0.20 listing fee, 6.5% transaction fee и отдельные payment-processing fees; могут применяться дополнительные сборы. citeturn0search2turn0search7

Поэтому Etsy не соответствует строгому правилу «абсолютно €0 до публикации», если listing fee применяется.

## Что НЕ делаем

На первой стадии:
- собственный сайт;
- VPS;
- домен;
- платную рекламу;
- подписки;
- сложный SaaS.

## Стратегия

Один продукт → один бесплатный/условно бесплатный канал → QA → публикация → наблюдение → второй канал → только потом масштабирование.
