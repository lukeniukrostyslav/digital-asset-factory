# V2.29 — PHYSICAL ANDROID VISUAL ACCEPTANCE FEEDBACK

Дата: 24.09.2026

## Статус

**Physical Android visual acceptance: NOT PASSED**

Файл V2.29 открылся на Android и рабочие листы отображаются, но по предоставленным скриншотам выявлены визуальные проблемы, которые нельзя считать финально принятыми.

## Наблюдения

### Savings Goals
- Русские заголовки отображаются.
- Первый столбец и часть правых столбцов визуально ограничены шириной экрана.
- Заголовок «Остаток» справа обрезается.
- Формулы/значения отображаются, признаков ошибки восстановления файла нет.

### Transactions
- Структура и данные читаются.
- Таблица работает на Android.
- Длинные значения в Description визуально обрезаются (например, Monthly salary).
- Для коммерческой mobile-first версии требуется дополнительная настройка ширины/переноса текста.

### Budget
- Таблица читается и значения отображаются.
- Названия категорий в первом столбце частично обрезаются слева из-за текущего горизонтального viewport.
- Заголовок «Разница» помещается тесно.
- После таблицы остаётся большой пустой вертикальный участок.
- Нужна дополнительная мобильная компоновка/ширины колонок.

## Gate decision

Android opening/working gate: **PASS**

Premium mobile visual acceptance: **NOT PASS**

Причина: визуальная читаемость отдельных колонок и длинных текстовых полей ещё недостаточна для финального commercial acceptance.
